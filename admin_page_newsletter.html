How Publishing Works

Admin: Create article → Add Article → Generate JSON Files

The admin page creates:
json/
├── manifest.json
├── article-001.json
├── article-002.json
├── article-003.json
└── ...
Your public index.html reads manifest.json, discovers the published articles and displays them automatically.
